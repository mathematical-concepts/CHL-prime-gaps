# CHL3 strict low-wheel pairwise Möbius patch

This patch implements the correction suggested by the mathematical review of the
CHL3 low-wheel cumulant experiment.

## Problem fixed

The previous low-wheel cumulant aggregated full-horizon interior probabilities
and multiplied them by a low-wheel coupling factor.  This did detect some hard
zeros, but it did not implement the strict low-wheel pairwise cumulant

$$
\kappa_{uv}^{low}
= \frac{1}{(\log x)^2}\frac{\mathfrak S_{low}(H_5(u,v))}{\mathfrak S_{low}(H_3)} - p_u^{low}p_v^{low}
$$

The decisive q=3 mechanism occurs when two interior candidates occupy the two
remaining reduced classes and the quintet covers all classes modulo 3.  Then
$\mathfrak S_{low}(H_5)=0$, so the pair contributes exactly
${-p_u^{low}p_v^{low}}$ to the cumulant.  Subtracting this negative cumulant
increases $\Omega^{(2)}$ and lowers survival probability.

## Implementation

The base first-order CHL2 intensity remains full-horizon:

$$
\Omega^{(1)} = \sum_u \frac{1}{\log x}
\frac{\mathfrak S_Y(H_4(u))}{\mathfrak S_Y(H_3)}.
$$

The cross-cumulant is evaluated on the selected low wheel only.  No early exit
on `(v-u) mod q` is used.  The sum over concrete pairs `u < v` is aggregated
exactly by residue classes modulo

$$
M_{low}=\prod_{q\in Q_{low}}q,
$$

so it remains fast while preserving the hard Möbius zeros.

The resulting models keep the same names:

- `CHL3_lowwheel2_p3_cond_eta`
- `CHL3_lowwheel2_p3p5_cond_eta`
- `CHL3_lowwheel2_p3p5p7_cond_eta`
- `CHL3_self_lowwheel2_p3_cond_eta`
- `CHL3_self_lowwheel2_p3p5_cond_eta`
- `CHL3_self_lowwheel2_p3p5p7_cond_eta`

but their kappa term is now strict low-wheel pairwise Möbius.
